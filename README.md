# 《重返未来：1999》战斗伤害建模与配置收益分析工具

基于 Excel 独立构建的战斗伤害模拟与配置收益分析工具。

通过拆解角色属性、技能倍率、心相效果、Boss机制及动态战斗状态，
建立可进行实战验证的伤害模型，并进一步用于不同塑造、心相增幅及角色配置下的收益比较。

### 项目成果

- 完成战斗伤害计算模型与行动状态模拟逻辑
- 对104项实战伤害进行逐项验证，预测结果与游戏实测一致
- 累计核对伤害2,321万，并在验证模型基础上开发参数化配置收益分析工具

## 1. 项目背景

《重返未来：1999》的战斗伤害受到角色面板、技能倍率、暴击、
增伤/减伤、动态增益、行动顺序及特殊战斗阶段等多种因素共同影响。

本项目希望解决两个问题：

1. 能否建立一套能够复现实战伤害结果的计算模型？
2. 在统一战斗环境和行动序列下，如何量化不同塑造、心相增幅及配置的实际收益？


## 2. 分析流程

机制整理 → 数值建模 → 状态模拟 → 实战采样 → 误差定位
→ 专项测试 → 模型修正 → 配置收益分析


## 3. 伤害模型

模型将战斗伤害拆分为多个独立计算环节，包括：

- 角色攻击与基础面板
- 技能倍率
- 敌方防御
- 暴击相关参数
- 威力相关增益
- 创伤加成
- 伤害减免
- 现实 / 精神 / 本源伤害
- 特殊技能及阶段修正


## 4. 战斗状态模拟

为处理战斗过程中动态变化的数值，建立按行动更新的状态逻辑，
主要处理：

- Buff叠层及持续时间
- 状态触发与结算顺序
- 反击与追击
- 额外回合
- 目击机制
- 弱点洞穿阶段
- 不同行动之间的状态继承与更新

因此模型并非仅计算单次静态技能伤害，而能够按照预设行动序列模拟完整战斗过程。


## 5. 实测验证

为验证模型准确性，记录实际游戏战斗过程，并将模型预测结果与实测伤害逐项比较。

验证数据包括：

- 7个主线回合
- 1个额外回合
- 2个洞穿阶段
- 104项伤害记录
- 累计核对伤害2,321万

### 验证流程

预测伤害
→ 实战记录
→ 对比误差
→ 定位可能影响变量
→ 设计专项测试
→ 修正计算逻辑
→ 再次验证

对于出现差异的项目，针对技能倍率、暴击精度、效果结算时点等因素进行专项测试，
通过控制变量定位误差来源，并根据验证结果修正模型。

### 验证结果

在最终采用的计算规则下，已记录的104项伤害预测结果与游戏实测结果一致。


## 6. 配置收益分析

在完成伤害模型实测验证后，进一步开发参数化配置收益分析工具。

可调整变量包括：

- 角色面板
- 0–5塑造
- 心相增幅
- Boss固定属性
- 部分效果参数

在保持敌方属性与行动序列一致的情况下，通过控制变量比较不同配置的：

- 总伤害
- DPR
- 角色伤害占比
- 技能伤害占比
- 相对提升率


## 7. 项目说明
- 本项目为个人学习及游戏数值分析作品，与游戏官方无关。
- 游戏相关名称及素材版权归原权利方所有。
- 项目中的分析模型基于公开游戏表现及个人实测结果整理。
- Excel展示版仅开放部分参数输入区域，底层计算区域已进行保护。
- 本项目主要用于个人求职作品展示及数值策划能力说明。
